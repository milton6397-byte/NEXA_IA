# NEXA IA

**Assistente de Inteligência Artificial local desenvolvida em Python.**

A NEXA IA é um projeto experimental criado por Milton Cesar Martins, com o objetivo de estudar e desenvolver uma assistente local utilizando programação, inteligência artificial e integração com modelos de linguagem.

## Funcionalidades atuais

- Interface gráfica desenvolvida com Kivy.
- Comunicação com um modelo local Qwen por meio do llamafile.
- Conversação em português brasileiro.
- Histórico de mensagens durante a execução.
- Identidade e instruções de comportamento personalizadas.

## Tecnologias utilizadas

- Python
- Kivy
- Qwen
- llamafile
- Git e GitHub

## Objetivo do projeto

Desenvolver conhecimentos práticos em programação, inteligência artificial e integração entre software e hardware, evoluindo gradualmente a NEXA IA.

## Status

Projeto em desenvolvimento. As funcionalidades e capacidades da assistente estão sendo ampliadas conforme os estudos e testes.
